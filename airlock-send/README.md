# Airlock Send

Companion to [Airlock](https://github.com/FlashCosmos/AirLock). When Claude opens a new Claude tab
with a handoff brief, Airlock Send presses that tab's Send button, so the brief goes out without you
pressing Enter.

It runs on your own computer, where the VS Code window is, so one install also covers your
Remote-SSH and Remote Tunnel windows. Windows only for now. See the Airlock README for limitations.
